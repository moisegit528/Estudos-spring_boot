# 📚 Estudos com Spring Boot

Este repositório reúne meus projetos e estudos práticos utilizando **Java** e **Spring Boot**, com foco em **API REST**, **Spring Data JPA**, **Hibernate** e boas práticas de desenvolvimento back-end.

---

## 🚀 Projetos incluídos
- **todolist** → Aplicação de lista de tarefas para praticar CRUD e persistência de dados.  
- **spring_boot_jpa_delivery_local** → Sistema de delivery local para treinar relacionamentos entre entidades e consultas com JPA.  

---

## 🧩 Tecnologias utilizadas
- Java 17  
- Spring Boot  
- Spring Data JPA  
- Hibernate  
- MySQL  
- Maven  
- Postman  

---

## 🔗 Objetivo
Este repositório foi criado para:
- Consolidar meus estudos em **Spring Boot**.  
- Praticar **modelagem de entidades** e **relacionamentos JPA**.  
- Criar APIs REST organizadas e escaláveis.  
- Servir como portfólio de aprendizado no GitHub.
