# Spring Boot API REST - Delivery Local

Projeto desenvolvido para estudos de desenvolvimento backend utilizando Java e Spring Boot.

## Objetivo

Praticar a criação de uma API REST, aplicando conceitos como:

* Controllers
* Services
* Repositories
* DTOs
* Entidades JPA
* Configurações do Spring Boot

## Tecnologias utilizadas

* Java
* Spring Boot
* Spring Web
* Spring Data JPA
* Hibernate
* Maven
* Git

## Sobre o projeto

Este projeto faz parte dos meus estudos em desenvolvimento de APIs REST com Spring Boot, buscando aprimorar conhecimentos em arquitetura backend, organização de código e boas práticas de desenvolvimento.
